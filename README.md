Blackbaud is a cloud software company for the social impact sector: nonprofits, foundations, K-12 private schools, higher education, healthcare organizations and corporate social responsibility programs. Its products include Raiser's Edge NXT (donor CRM), Financial Edge NXT (fund accounting), Blackbaud CRM, Altru (arts and cultural organizations), Education Management, Grantmaking, GrantsConnect, CSRconnect (YourCause) and Blackbaud Merchant Services. Developers build on the SKY API, a REST API platform behind Azure API Management at api.sky.blackbaud.com with 60 published APIs (constituents, gifts, fundraising, events, general ledger, payments, school, OneRoster, webhooks and more), authorized with Blackbaud ID OAuth 2.0 authorization-code flow plus a Bb-Api-Subscription-Key, and listed in the Blackbaud Marketplace.

**Areas:** Non-Profit · Fundraising · Donor Management · CRM · Fund Accounting · Education · Grantmaking · Payments · Philanthropy · Social Impact
